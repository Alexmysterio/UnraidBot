# Código de conducta

## Nuestro compromiso

Como miembros y mantenedores, nos comprometemos a hacer de la participación en
este proyecto una experiencia libre de acoso para todo el mundo,
independientemente de edad, identidad y expresión de género, nivel de
experiencia, nacionalidad, apariencia, religión o identidad sexual.

## Nuestras normas

Ejemplos de comportamiento que crean un entorno positivo:

- Usar un lenguaje amable e inclusivo.
- Respetar puntos de vista y experiencias diferentes.
- Aceptar críticas constructivas con elegancia.
- Centrarse en lo que es mejor para la comunidad.
- Mostrar empatía con otras personas de la comunidad.

Ejemplos de comportamiento inaceptable:

- Lenguaje o imágenes sexualizadas, y atención sexual no deseada.
- Comentarios insultantes o despectivos, ataques personales o políticos.
- Acoso público o privado.
- Publicar información privada de terceros sin permiso.
- Publicar tokens, API keys o datos de servidores ajenos.
- Cualquier conducta que razonablemente se considere inapropiada en un entorno
  profesional.

## Aplicación

Los mantenedores pueden eliminar, editar o rechazar comentarios, commits, issues
y PRs que no cumplan este código, y pueden banear temporal o permanentemente a
quien incumpla.

Para reportar un incidente, contacta con el mantenedor a través de GitHub de
forma privada. Las denuncias se revisarán y se tratarán con confidencialidad.

## Atribución

Este código está adaptado del [Contributor Covenant](https://www.contributor-covenant.org/),
versión 2.1.
